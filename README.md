# Proyecto Pastoral Tarbesiano 2026-2027

Este proyecto contiene la página web interactiva para la **Propuesta Pastoral SJT 2026-2027: "Renacer en el Espíritu, Juntos"**.

## 🚀 Tecnologías Utilizadas

*   **HTML5**
*   **Tailwind CSS** (vía CDN para desarrollo rápido y sin dependencias complejas).
*   **JavaScript (Vanilla)** para interacciones de interfaz (pestañas, menú).
*   **Google Fonts**: Bebas Neue (Títulos), Montserrat (Cuerpo) y Futura/System-fonts.
*   **FontAwesome**: Para íconos vectoriales.

## 📂 Estructura del Proyecto

*   `index.html`: Archivo principal con todo el maquetado y lógica de la landing page.
*   `assets/`: Carpeta para recursos estáticos.
    *   `hero-bg.jpg`: Fotografía principal de la comunidad para la cabecera.
    *   `logo-sjt-azul.png`: Logo principal de las Hermanas de San José de Tarbes.
    *   `logo-sjt-blanco.png`: Logo en versión negativa para fondos oscuros.
    *   *(Agrega aquí los recortes del logo pastoral y otras fotos)*.

## 🎨 Paleta de Colores Configurada

*   **Primarios:** Azul Oscuro (`#020F79`), Gris (`#D9D9D9`), Amarillo (`#FFC700`).
*   **Secundarios:** Azul Claro (`#586195`), Oscuro/Negro (`#00010F`), Blanco (`#FFFFFF`).

## 💻 Siguientes Pasos (Para el Desarrollador)

1.  **Imágenes Finales:** Busca en el código `index.html` las etiquetas `<img>` que contienen URLs de *Unsplash* (`https://images.unsplash.com/...`) y reemplázalas por fotos reales de los colegios, estudiantes y agrupaciones juveniles Tarbesianas.
2.  **Logo Pastoral:** Sustituye el espacio en la sección "Explicación del Logo" por los vectores/pngs individuales de la cruz, el camino y las personas.
3.  **Despliegue:** Puedes subir este repositorio directamente a **GitHub Pages**, **Vercel** o **Netlify** ya que es un sitio estático 100% optimizado.
